> Cenário reproduzível com `STORE_TODAY=2026-02-20` no `.env`.

**Cliente:** Meu pedido 8 chegou? Meu nome é Ana Carolina Ferreira e meu telefone é (67) 99654-7821.

**Agente:** Localizei seu cadastro, Ana. Sobre o **pedido 8**:

- **Status:** enviado
- **Data do pedido:** 15/02/2026
- **Previsão de entrega:** 28/02/2026
- **Rastreio:** BRJL5544332BR
- **Item:** Kala KA-C Concert Mogno — 1 unidade — R$ 349,90
- **Total:** R$ 349,90
- **Pagamento:** cartão de débito

**Cliente:** Consegue ver se já saiu para entrega?

**Agente:** O status registrado no sistema é **enviado**, com previsão para 28/02/2026. O sistema não mostra o evento detalhado de “saiu para entrega”; para essa informação, o ideal é acompanhar o rastreio **BRJL5544332BR** ou falar com a equipe. Quer que eu encaminhe para um atendente confirmar?
